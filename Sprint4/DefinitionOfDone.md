# Definition of Done

User Story se smatra završenim kada:
- je implementiran u potpunosti prema Acceptance Criteria (AC) 
- je pull request istog pregledan, komentari međusobno riješeni i odobren od strane barem jednog člana tima
- je testirana prema dokumentu Test Strategy
- je evidentirana i ažurirana u relevantnim artefaktima 
- je spreman za demonstraciju u sprint reviewu
- Product Owner prihvati da je User Story odrađen
- je isti mergean na main branch bez ikakvih konflikata
