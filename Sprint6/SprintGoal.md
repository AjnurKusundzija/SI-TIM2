# Sprint Goal – Sprint 6

## Sprint cilj

Cilj sprinta je unaprijediti funkcionalnosti ticket sistema kroz implementaciju detaljnog prikaza tiketa, komunikacije između korisnika i agenata, pregleda svih tiketa za administratore i agente, te proširenje sistema FAQ segmentom i unapređenom autorizacijom ruta.

Sprint je fokusiran na razvoj naprednijeg sistema za upravljanje tiketima kako bi korisnici, agenti i administratori imali jasniji pregled statusa prijava, komunikacije i aktivnosti unutar sistema podrške. Poseban fokus stavljen je na unapređenje korisničkog iskustva, navigacije između stranica i sigurnosti pristupa kroz pravilnu autorizaciju ruta i kontrolu pristupa na osnovu korisničkih uloga.

Također, sprint uključuje pripremu sistema za real-time komunikaciju korištenjem SignalR/WebSocket tehnologija, unapređenje backend API strukture i povezivanje frontend komponenti sa novim funkcionalnostima ticket sistema.

Dodatni cilj sprinta je standardizacija načina prikaza i upravljanja tiketima za različite korisničke role, uz poboljšanje organizacije frontend komponenti, backend endpointa i validacije pristupa podacima. Implementacijom detaljnog prikaza tiketa omogućava se lakše praćenje aktivnosti, statusa i komunikacije unutar sistema podrške, čime se unapređuje efikasnost rada agenata i transparentnost prema korisnicima.

Sprint također obuhvata unapređenje strukture ruta, prilagođavanje API endpointa standardima projekta, refaktorisanje postojećih komponenti i pripremu sistema za buduća proširenja kao što su notifikacije, dashboard funkcionalnosti i napredni sistemi za upravljanje tiketima.

Kroz implementaciju FAQ segmenta tim radi i na smanjenju broja nepotrebnih prijava korisničkoj podršci, omogućavajući korisnicima pristup često postavljanim pitanjima i osnovnim informacijama prije kreiranja tiketa.

## Sprint Review kriterij

Ocjenjuje se funkcionalnost ticket sistema, ispravnost autorizacije, pregled komunikacije kroz tiket, kvalitet implementacije i uspješnost testiranja sistema.

Posebna pažnja biće posvećena stabilnosti navigacije između stranica, pravilnom prikazu podataka za različite korisničke role, kvalitetu frontend-backend integracije, te mogućnosti daljeg proširenja sistema real-time komunikacijom i dodatnim funkcionalnostima u narednim sprintovima.

Review uključuje provjeru:
- Ispravnosti autorizacije po korisničkim rolama
- Funkcionalnosti detaljnog prikaza tiketa
- Stabilnosti komunikacije kroz tiket
- Tačnosti prikaza svih tiketa za agente i administratore
- Kvaliteta implementacije FAQ sistema
- Ispravnosti frontend i backend integracije
- Navigacije između ticket liste i detalja
- Stabilnosti API endpointa
- Kvaliteta organizacije komponenti i ruta
- Pokrivenosti testovima i stabilnosti aplikacije
- Spremnosti sistema za naredne sprint funkcionalnosti
